# Governance Automation

This directory is the source of truth for branch governance rollout across:

- `furnished-condos`
- `chittycorp`
- `chittyos`
- `chittyapps`
- `chicagoapps`

## Autopilot

Workflow: `.github/workflows/org-governance-autopilot.yml`

It runs:

1. `scripts/apply-org-rulesets.sh` for org-level rulesets (when org plan supports it)
2. `scripts/apply-repo-branch-protections.sh --apply` for repo-level fallback

The fallback ensures new repos are picked up automatically on each scheduled run, so you do not need to manually apply protection per repository.

## Required Secret

Create org/repo secret in `chittyops`:

- `ORG_GOVERNANCE_TOKEN`

Recommended scopes for classic PAT:

- `admin:org` (org rulesets)
- `repo` (repo branch protection updates)

## Check inventory is observed data

`compliance/rulesets/check-inventory/*.txt` is regenerated by
`scripts/discover-org-checks.sh` from the checks GitHub actually reports per repo. Do not
hand-edit it — edits are overwritten on the next run, and a hand-edited file no longer
describes what is really running.

Two entries there name the retired 1Password lane (`1Password Rotation Audit / audit`
under `chittyos`, `Deploy with 1Password / deploy` under `chittycorp`). They are
observations of checks that still exist upstream, not endorsements. **Never promote a
1Password-lane check to a required check** in `scripts/generate-org-rulesets.py`:
1Password is retired as both a credential lane and a declared authority as of 2026-08-21,
the cold source of truth is ChittySecrets (`secrets.chitty.cc`, fronting Cloudflare
Secrets Store), and `op` has zero accounts on the ops host — such a check can only emit
false findings. Retiring those upstream workflows is an operator act in their own repos.

## Manual Commands

Regenerate inventory + ruleset payloads:

```bash
bash ./scripts/discover-org-checks.sh furnished-condos chittycorp chittyos chittyapps chicagoapps
python3 ./scripts/generate-org-rulesets.py furnished-condos chittycorp chittyos chittyapps chicagoapps
```

Apply org rulesets:

```bash
bash ./scripts/apply-org-rulesets.sh furnished-condos chittycorp chittyos chittyapps chicagoapps
```

Apply repo fallback protections:

```bash
bash ./scripts/apply-repo-branch-protections.sh --apply furnished-condos chittycorp chittyapps chicagoapps
```
